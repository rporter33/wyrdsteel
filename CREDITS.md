# Credits

Wyrdsteel ships with **no third-party art, models, textures, fonts or audio.** Every mesh is
built from primitives in code (`src/render/models/`), every sound is synthesized with the Web
Audio API (`src/audio/`), and the interface uses the system font.

Names of gods, places and creatures come from Norse mythology (the Poetic and Prose Eddas),
which is in the public domain.

Runtime libraries: [three.js](https://threejs.org) (MIT), [Preact](https://preactjs.com) (MIT).
